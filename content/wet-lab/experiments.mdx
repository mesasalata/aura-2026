<Section id="overview" title="Experimental plan" kicker="01">

Experiments follow AURA's five DBTL cycles. Each assay answers one question before we commit to the next design: does miR-223 bind the catapult, does the FET tick, can the siphon sit in the line. This page is the map; protocols and the notebook hold the detail.

<Callout variant="note" title="Status">
  Some runs are scheduled or in progress. Results land on the Results page as data arrives.
</Callout>

</Section>

<Section id="goals" title="Goals" kicker="02">

1. Confirm that bta-miR-223 can be detected in milk matrix
2. Characterise DNA-catapult opening against miR-223 versus irrelevant RNA
3. Measure FET current change when the catapult opens
4. Validate reference electrodes against salty milk so salt does not raise a false flag
5. Compare the on-farm load score against SCC / culture references where samples allow

</Section>

<Section id="assays" title="Assay pipeline" kicker="03">

| Phase | Assay | Question |
| --- | --- | --- |
| 1 | Literature + spiking design | Is the miR-223 window realistic in milk? |
| 2 | Catapult opening screen | Does recognition work in milk? |
| 3 | FET current traces | Does the transistor report? |
| 4 | Electrode baseline | Does this sample's own salt cancel out? |
| 5 | Consecutive-session flag | Is one spike a verdict, or do we wait? |

</Section>

<Section id="controls" title="Controls" kicker="04">

Every experiment includes positive controls (known miR-223 spike), negative controls (unspiked milk, irrelevant RNA), and matrix blanks. FET runs always include the upstream reference electrodes so the residual is against that sample, not a generic zero.

</Section>

<Section id="samples" title="Samples" kicker="05">

<Section id="timeline" title="Timeline" kicker="06">

Assays follow the engineering cycles: catapult opening before FET traces, FET traces before siphon integration, siphon before the consecutive-session flag. Parallel dry-lab modeling informs which conditions to test first, reducing wasted bench time.
